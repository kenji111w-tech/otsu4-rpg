## Part B：06_授業_合言葉_キャラクター（要修正のみ）

明らかな法令・数値の誤りは見つからなかった。以下はすべて「言い切りすぎ・誤解のおそれ」の軽微な指摘。

1. **Q2-4（燃料のお店）**「第1種は1階に置きます」
   - 理由：1階に設けるのは第1種・第2種の両方。この書き方だと「第2種は1階でなくてよい」と読める。
   - 直し方：「どちらも建物の1階に置きます」。
2. **H1-2（油の集会所）**「引火点が常温より低いものが多く」
   - 理由：品名でみると、常温（20℃）より引火点が低いのは特殊引火物・第1石油類・アルコール類まで。第2〜第4石油類・動植物油類は常温より高く、「多い」とは言いにくい。
   - 直し方：「引火点が常温より低いものもあり（ガソリンなど）」。
3. **P1-1（かまどの広場）**「さびは熱と光を出さないので燃焼ではない」
   - 理由：さび（ゆるやかな酸化）でも熱は出る（使い捨てカイロや自然発火の説明とも食いちがう）。出ないのは光で、熱は少しずつしか出ない。
   - 直し方：「さびは熱がゆっくりしか出ず、光も出さないので燃焼ではないわ」。
4. **L3-1（給油所の裏）**「資格のない人も、甲種か乙種の立会いがあれば扱えます」
   - 理由：乙種が立ち会えるのは免状に書かれた類だけ（AK014やL3-bossの言い直しには条件が入っている）。
   - 直し方：「甲種か、その類の乙種の立会いがあれば扱えます」。
5. **D3-2（規程の書庫）**「給油取扱所・移送取扱所は量にかかわらず必要」
   - 理由：給油取扱所のうち、屋外の自家用給油取扱所は予防規程の対象外という例外がある（鉱山保安法などの適用を受ける施設も除外）。
   - 直し方：「給油取扱所（屋外の自家用を除く）・移送取扱所は量にかかわらず必要」、または「原則として」を入れる。
6. **H1-4（泡の消防小屋）**「第4類の火事に水はダメ。棒状でも霧状でも、油が水に浮いて火が広がる」
   - 理由：結論（水は適さない）は試験どおりだが、「水に浮く」という理由はアルコールなどの水溶性のものや二硫化炭素など水より重いものには当てはまらない。H1-2で「『すべて』と言われたら疑え」と教えているのと食いちがう。
   - 直し方：「第4類の火事に水は向かない。多くは水に浮いて火が広がるからだ」。
7. **AK018（定期点検）**「1年に1回以上行い、記録は3年間保存する」
   - 理由：授業L3-4には「原則」があるのに合言葉では抜けている（地下タンクなどの漏れの点検や、移動貯蔵タンクの水圧試験の記録は周期・保存年数が別）。
   - 直し方：「原則1年に1回以上、記録は原則3年間保存」。
